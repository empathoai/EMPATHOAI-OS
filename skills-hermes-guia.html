Cómo crear tu propia skill

De acuerdo: puedes darme una idea, un procedimiento o una herramienta y puedo convertirlo en una skill configurable para Hermes.

Información útil que puedes proporcionar

  • Nombre y objetivo concreto.
  • Cuándo debe activarse y cuándo no.
  • Herramientas, cuentas, APIs o archivos necesarios.
  • Pasos que quieres que siga.
  • Cómo comprobar que terminó correctamente.
  • Qué opciones deben evitar costes o pedir confirmación.

Formato recomendado para pedírmela

“Crea una skill llamada nombre para hacer objetivo. Solo puede usar dependencias. Prioriza opciones gratuitas/locales y pídeme confirmación antes de cualquier coste.”
