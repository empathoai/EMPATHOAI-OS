# Operating Principles

1. **Human-first:** technology amplifies human judgment; it does not replace it.
2. **Compliance-first:** decisions and systems operate with rigor, security, and compliance.
3. **Precision over volume:** prioritize quality and correct decisions over noise.
4. **Do not scale disorder:** correct the base before increasing reach.
5. **Evidence before adaptation:** apply source frameworks faithfully before changing them based on observed reality.
6. **Execution before architecture:** add structure only when it solves a demonstrated problem.
7. **Manual before automation:** define, execute, and validate a process before delegating or automating it.
8. **Maximum three strategic priorities:** keep no more than three active priorities per 90-day cycle.
9. **Escalate by impact:** threats to cash, clients, capacity, deadlines, or company priorities escalate immediately.
10. **One task per session:** keep each execution focused on one task and defer unrelated work to preserve context and recoverability.

## Operating rhythm

```text
DOR -> WOR -> MOR
```

- **DOR:** daily review of cash, delivery, leads, priorities, blockers, and deviations.
- **WOR:** Monday weekly review of reality, commitments, risks, constraints, decisions, and plan.
- **MOR:** monthly strategic review of patterns, root causes, priorities, offers, and processes.

Every action follows:

```text
Problem -> Cause -> Action -> Owner -> Deadline -> Expected evidence -> Status
```
